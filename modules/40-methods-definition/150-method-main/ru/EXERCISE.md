
Реализуйте класс с именем `App` и двумя методами:

1. Метод `gogo()` без параметров, который печатает на экран строку `It works!`
2. Метод `main()` с сигнатурой `public static void main(String[] args)`, который вызывает метод `gogo()`

Результат вызова `main()` в таком случае будет таким:

```java
// => "It works!"
```
