
Write a program that takes the initial amount of euros written in the variable `eurosCount`, converts euros to dollars, and prints the result to the screen. Then it converts the resulting value to rubles and prints it on a new line.

Example output for 100 euros:

```text
125.0
7500.0
```

We assume that:

- 1 euro = 1.25 dollars
- 1 dollar = 60 rubles
