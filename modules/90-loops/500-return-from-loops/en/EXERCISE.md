
Implement the static method `App.hasChar()`, which checks (taking the case into account) whether a string contains the specified letter. The method accepts two parameters:

* The string
* The letter to search for

```java
App.hasChar("Renly", 'R'); // true
App.hasChar("Renly", 'r'); // false
App.hasChar("Tommy", 'm'); // true
App.hasChar("Tommy", 'd'); // false
```
