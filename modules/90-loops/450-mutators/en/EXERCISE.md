
Implement the static method `App.makeItFunny()`, which accepts a string and returns its copy in which every n-th element is converted to upper case. n is set as an input of the function. To determine every n-th element you will need the remainder of division `%`. Think about how it can be used.

```java
var text = "I never look back";
// Every third element
App.makeItFunny(text, 3); // "I NevEr LooK bAck"
```
