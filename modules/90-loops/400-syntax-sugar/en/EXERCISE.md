
Implement the static method `App.filterString()`, which accepts a string and a character and returns a new string in which the passed character is removed in all of its positions.

An example of a call:

```java
var str = "If I look back I am lost";
App.filterString(str, 'I'); // "f  look back  am lost"
App.filterString(str, 'o'); // "If I lk back I am lst"
```
