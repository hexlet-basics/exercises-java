Java, как и любой другой язык, поставляется с набором полезных методов. Все вместе они составляют так называемую **стандартную библиотеку**. В нее обычно входят тысячи методов, которые невозможно выучить — этого и не нужно делать. Подразумевается, что любой программист знает, где искать документацию по ним и примерно представляет себе, чего он хочет достичь. А дальше — дело техники. Если отнять у программистов интернет, то большинство не сможет ничего запрограммировать.

Для новичков эта информация часто выглядит так: «Сходи туда, не знаю куда, принеси то, не знаю что». То есть непонятно, как узнавать про эти методы, когда ты ничего не знаешь вообще. Как ни странно, не существует способа раз и навсегда познать все, что нужно познать. Любой разработчик в процессе своего профессионального взросления знакомится со все более интересными методами, решающими его задачи более элегантно, и таким образом пополняет свой арсенал.

Вот некоторые советы, как узнавать о новых методах:

- Всегда четко отслеживайте, с каким типом данных вы сейчас работаете. Почти всегда вы найдете необходимый метод в соответствующем разделе документации — например, для работы со строками нужно изучать строковые методы
- Периодически открывайте раздел со стандартными методами по изучаемой тематике и просто пробегайтесь по ним, изучая сигнатуры и способы использования
- Чаще читайте чужой код, особенно код библиотек, которые вы используете. Он весь доступен на GitHub

Предположим, нужно убрать пробелы по краям строки. Для поиска подходит [документация класса `String`](https://docs.oracle.com/en/java/javase/26/docs/api/java.base/java/lang/String.html). Раздел Method Summary содержит список методов с краткими описаниями. В нём `trim()` описан как метод, возвращающий строку без начальных и конечных пробелов. По ссылке `trim()` открывается подробный контракт. Для строки `"  Java  "` вызов `trim()` возвращает `"Java"`. Числовые операции, например модуль числа, находятся в [документации класса `Math`](https://docs.oracle.com/en/java/javase/26/docs/api/java.base/java/lang/Math.html).

## Как читать документацию метода

Документация описывает, какие данные принимает метод и какой результат возвращает. Справка о стандартной библиотеке Java собрана по классам, и у каждого класса своя страница. На странице класса есть два раздела, которые нужны для вызова. Раздел Method Summary перечисляет методы класса таблицей, а раздел Method Details подробно описывает каждый метод.

Разберём метод `indexOf()`, который ищет подстроку и возвращает её позицию. В таблице Method Summary у каждого метода указаны тип результата, имя с параметрами и краткое описание. Для `indexOf()` в таблице несколько строк, среди них такие две.

```text
int    indexOf(String str)
int    indexOf(String str, int fromIndex)
```

Если щёлкнуть по имени метода, откроется его описание в разделе Method Details. Ниже приведено описание второй версии, часть текста пропущена.

```text
public int indexOf(String str, int fromIndex)

Returns the index within this string of the first occurrence of the
specified substring, starting at the specified index.
...

Parameters:
    str - the substring to search for.
    fromIndex - the index from which to start the search.
Returns:
    the index of the first occurrence of the specified substring,
    starting at the specified index, or -1 if there is no such occurrence.
```

Описание читают сверху вниз по шагам.

1. Первая строка содержит запись метода с типом результата, именем и параметрами.
2. Первое предложение кратко говорит, что делает метод.
3. Дальше идут подробности. В них бывают формулы и примечания, на первом чтении их можно пропустить.
4. Раздел Parameters объясняет каждый параметр по имени из записи. Здесь `fromIndex` означает индекс, с которого начинается поиск.
5. Раздел Returns описывает результат, включая особые случаи. Здесь метод возвращает `-1`, если подстроки нет.

В таблице сопоставлены части записи и аргументы вызова `"Java".indexOf("a", 2)`.

| Часть записи | Что она означает | В вызове `"Java".indexOf("a", 2)` |
| --- | --- | --- |
| `public` | Метод доступен из любого кода | Вызываем метод из своей программы |
| `int` | Тип результата, целое число | Получаем позицию символа |
| `indexOf` | Имя метода | Вызываем `indexOf()` у строки `"Java"` |
| `String str` | Параметр типа `String`, подстрока для поиска | Передаём `"a"` |
| `int fromIndex` | Параметр типа `int`, позиция начала поиска | Передаём `2` |

Запись показывает, какие аргументы передать, а описание объясняет, что получится. Проверим это вызовами.

```java
System.out.println("Java".indexOf("a")); // => 1
System.out.println("Java".indexOf("a", 2)); // => 3
System.out.println("Java".indexOf("a", 4)); // => -1
```

Первый вызов находит первую букву `a` на позиции `1`. Второй начинает поиск с позиции `2` и находит вторую букву `a` на позиции `3`. Третий начинает с позиции `4`, где строка уже закончилась, поэтому возвращает `-1`, как и обещает раздел Returns.

## Перегрузки вместо необязательных параметров

В Java у параметров метода нет значений по умолчанию. Если аргумент можно не передавать, в классе объявлено несколько методов с одним именем и разными параметрами. Такие методы называются **перегрузками**. Поэтому в Method Summary у `indexOf()` несколько строк. Версия `indexOf(String str)` ищет с начала строки, а версия `indexOf(String str, int fromIndex)` ищет с указанной позиции.

Java выбирает перегрузку по аргументам вызова. Вызов `"Java".indexOf("a")` с одной строкой попадает в первую версию, вызов `"Java".indexOf("a", 2)` со строкой и числом попадает во вторую. Чтобы понять, чем версии отличаются, читают описание каждой из них.

## Обозначения в справке

В записях методов встречаются служебные слова и знаки. Они помогают прочитать запись и при вызове в код не переносятся.

| Запись в справке | Как её читать |
| --- | --- |
| `int indexOf(String str)` | Тип стоит перед именем. `int` слева от метода это тип результата, `String` перед `str` это тип параметра |
| `static int max(int a, int b)` | Слово `static` означает, что метод вызывают через имя класса, например `Math.max(3, 7)` |
| `static String join(CharSequence delimiter, CharSequence... elements)` | Многоточие после типа означает, что на этом месте можно передать любое количество аргументов |

Например, запись `static int max(int a, int b)` из справки класса `Math` описывает метод с двумя параметрами. Вызов `Math.max(3, 7)` передаёт числа `3` и `7` и возвращает `7`. Ни `static`, ни типы, ни имена `a` и `b` в вызов не копируются. В записи `join()` встречается тип `CharSequence`. На его место подходят и строки, поэтому вызов `String.join(":", "8", "30")` работает так же, как в уроке о переменном числе параметров.

Если браузер переводит страницу, имена методов, параметров и типы нужно сверять с оригиналом. В коде используются исходные имена из документации.

## Работа с незнакомым методом

Чтение справки начинается с задачи. Например, чтобы найти вторую букву `a` в слове, открываем страницу класса `String`, в Method Summary находим перегрузки `indexOf()`, в Method Details читаем, что делает `fromIndex`, и пробуем вызов `"Java".indexOf("a", 2)` в [JShell](https://onecompiler.com/jshell). Если результат соответствует описанию, вызов можно использовать в программе.
