
Implement the method `getNumberExplanation()`, which accepts a number and returns the explanation of this number. If there is no explanation for the number, then `just a number` is returned. Explanations exist only for the following numbers:

  * 666 - devil number
  * 42 - answer for everything
  * 7 - prime number

Examples of calls of the function:

```java
App.getNumberExplanation(8);   // just a number
App.getNumberExplanation(666); // devil number
App.getNumberExplanation(42);  // answer for everything
App.getNumberExplanation(7);   // prime number
```
