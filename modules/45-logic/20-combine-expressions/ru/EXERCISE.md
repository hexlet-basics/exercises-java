
Реализуйте метод `isInternationalPhone()`, который принимает телефон строкой и проверяет его формат. Если телефон начинается с _+_, значит это международный формат, и метод возвращает `true`, в остальных случаях `false`.

```java
App.isInternationalPhone("89602223423"); // false
App.isInternationalPhone("+79602223423"); // true
```
