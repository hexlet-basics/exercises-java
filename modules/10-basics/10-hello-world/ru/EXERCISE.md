Наберите в редакторе код из задания символ в символ и нажмите «Проверить».

```java
class App {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

Если вы напишете _heLLo, woRld!_ вместо _Hello, World!_, то это будет считаться другим текстом, потому что заглавные и строчные буквы — это разные символы. Размер буквы называют _регистром_, и говорят: **регистр — важен!** Это касается почти всего в коде, поэтому привыкайте всегда обращать внимание на регистр.
