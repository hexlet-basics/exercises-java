
Implement a program that calculates the value of the expression `8 / 2 + 5 - -3 / 2` and prints the result on the screen. Don't calculate anything yourself; your program must perform all the calculations on its own.
```text
10
```
Note that the interpreter performs arithmetic calculations in the correct order: first division and multiplication, then addition and subtraction. Sometimes this order needs to be changed — that's what the next lesson is about.

Also note that Java uses integer division by default, `3 / 2` will be `1`.
